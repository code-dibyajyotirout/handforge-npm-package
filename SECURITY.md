# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

The HandForge team takes software security seriously. If you discover a security vulnerability within this repository or npm package, please disclose it responsibly.

Do not create public GitHub issues for security vulnerabilities. Instead, please report vulnerabilities by emailing:

`code.dibyajyotirout@gmail.com`

Please include:
- A description of the vulnerability and its potential impact.
- Steps or proof-of-concept code to reproduce the issue.
- Details regarding your environment (browser version, operating system, WebGL/WebGPU support).

We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for remediation.
